# WebSecAudit

Open-source defensive security, configuration, and API hygiene tooling built in Rust (`rustls`).

## Flagship Project

- **[Website Vulnerability Scanner (`web-vuln-scanner`)](https://github.com/websecaudit/website-vulnerability-scanner)** — Non-destructive external web, OpenAPI 3.0, TLS 1.0–1.3, OWASP security headers, secret leak & DNS scanner with native GUI, CLI, and SARIF 2.1.0 CI/CD gates.
  - Documentation & Site: https://websecaudit.github.io/website-vulnerability-scanner/
  - Rust Crate (`crates.io`): https://crates.io/crates/website-vulnerability-scanner
  - Homebrew Tap: [`websecaudit/homebrew-tap`](https://github.com/websecaudit/homebrew-tap)
  - Windows Scoop Bucket: [`websecaudit/scoop-bucket`](https://github.com/websecaudit/scoop-bucket)
